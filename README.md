# PRCCDC — Pacific Signal

The selected light, map-led website design, prepared for Stu Steiner on September 12, 2026.

## Open the site

Extract the entire ZIP, then open `index.html` in a browser. Keep the HTML files and `assets` folder together. No installation, login, Node.js, paid service, or build step is required.

## Included files

- `index.html` — homepage, “Defend the Pacific Rim,” accurate regional map, event schedule, illustrative story, results, and participation links.
- `about.html` — competition background and volunteer roles.
- `history.html` — sourced historical milestones.
- `sponsors.html` — sponsor recognition and sponsorship information.
- `assets/` — CSS, navigation JavaScript, logos, and the regional map.

This package contains only the Pacific Signal pages. The two-design comparison bar and links to Command Floor have been removed. The design, colors, and content otherwise match the selected published proof. Shared CSS retains some unused rules from the original proof system; these do not load another design.

## Edit or host it

The HTML, CSS, and JavaScript are the editable source files, not a compiled or locked export. Edit page copy directly in the relevant HTML file. The homepage's original layout styles are in its `<style>` block; `assets/proofs.css` contains the Pacific Signal refinements, and `assets/site.css` provides the inner-page styles.

For GitHub Pages or another static host, place the four HTML files and the assets folder together in the published directory. No server-side code or proprietary hosting dependency is required. The included files do not modify the existing prccdc.com site unless you deliberately publish them there.

## Content and editor status

This is a static design handoff. It does not include an administrative editor, login, database, or automatic content synchronization. The separately developed local editor has not been integrated with this selected homepage yet.

The story is an explicitly fictional example, not the announced competition scenario. State geometry uses U.S. Census Bureau 2024 boundaries. History entries link to their sources. The organizer should verify dates, registration links, sponsor commitments, rules, and contact details before an official launch; the current pages identify unconfirmed details and preserve their qualifications. Sponsor and organizer logos remain their respective owners' marks.
